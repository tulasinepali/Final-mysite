    Excel Format Instructions

    The Excel file must have the following column headers in Row 1:

    Column Header Name Required? Description Example
    A question_text Yes The question text What is the capital of Nepal?
    B option_a Yes Option A text Kathmandu
    C option_b Yes Option B text Pokhara
    D option_c Yes Option C text Biratnagar
    E option_d Yes Option D text Lalitpur
    F correct_answer Yes Correct option: A, B, C, or D A
    G explanation No Explanation shown after answering Kathmandu is the capital city.
    H order No Question order number (auto-assigned if empty) 1
    Important Notes:
    • Row 1 must contain the exact column headers as shown above.
    • Headers are case-insensitive but must match the names exactly.
    • The correct_answer column must contain only A, B, C, or D.
    • Empty rows will be skipped automatically.
    • Rows with missing required fields will be skipped with an error message.
    • Maximum file size: 5MB.
    • Supported formats: .xlsx
